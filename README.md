# 🎨 The Digital Atelier

Projeto de uma landing page moderna e responsiva, inspirada em design premium de e-commerce, desenvolvida com **HTML puro e CSS puro (sem frameworks)**.

---

## 🚀 Sobre o projeto

O **The Digital Atelier** é uma interface elegante focada em:

* Layout moderno e minimalista
* Experiência visual premium
* Responsividade (mobile, tablet e desktop)
* Código limpo e organizado

Esse projeto foi originalmente baseado em um layout com Tailwind, mas foi **totalmente convertido para HTML + CSS puro**, ideal para aprendizado e controle total do estilo.

---

## 🧠 Tecnologias utilizadas

* HTML5
* CSS3
* Google Fonts
* Material Icons

---

## 📱 Responsividade

O projeto segue o conceito **mobile first**, funcionando bem em:

* 📱 Celulares
* 💻 Notebooks
* 🖥️ Telas grandes

Utiliza:

* Flexbox
* CSS Grid
* Media Queries

Esse projeto foi feito para:

* Praticar **conversão de frameworks (Tailwind → CSS puro)**
* Aprender **responsividade na prática**
* Servir como base para projetos reais ou portfólio
